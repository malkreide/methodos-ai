# Methodos AI

An expert-level RAG catalog of management methods.

Methodos AI is a Python 3.11+ RAG-CLI tool that recommends management methods
(SWOT, Porter's Five Forces, DACI, etc.) for a given problem statement.

```bash
methodos query "we need to enter a new market without burning cash"
```

See `docs/` for the design specification and implementation plan.
