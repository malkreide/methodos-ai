# Cost-Benefit Analysis

Put every cost and every benefit in money, over a stated horizon, discounted to
present value. The discipline is in what you are forced to admit you cannot price.

## When to use

- Capital expenditure, procurement, or infrastructure choices
- Anything a budget holder or auditor will ask you to justify with a number
- Comparing options with very different timing of costs and returns

## When *not* to use

- When the dominant benefits genuinely resist pricing — the model will quietly
  weight them at zero and produce a confident wrong answer
- Early exploration, where forecasts are invented rather than estimated
- As cover for a decision already taken; the assumptions will show it

## Facilitation outline (1–5 days)

1. Define the option set, including the honest do-nothing baseline.
2. List costs across the full life: build, run, train, migrate, decommission.
3. List benefits, and mark each one priced, proxied, or unpriceable.
4. Agree the horizon and the discount rate *before* computing anything.
5. Compute net present value per option.
6. Run sensitivity analysis. Report which single assumption flips the ranking —
   that sentence is usually more decision-relevant than the NPV itself.
7. Report the unpriceable benefits alongside the number, never inside it.

## Common pitfalls

- Omitting the do-nothing baseline, which flatters every option
- Counting build cost but not five years of operations
- Choosing the discount rate after seeing which answer it produces
- Burying step 7, so unpriceable effects silently count as zero
